- Components. Turn any layer into a component (⌥⌘K, or right-click) and place instances of it anywhere: change the main and every instance follows. Instances can change their text, images, colours and visibility, and components can have props such as a label, a toggle or a variant. Find them in Assets › Components; detach an instance to make it plain layers again. React export writes each component once with typed props, and the agent builds shared parts like a sidebar, nav or buttons as components instead of copies.
- The agent can work in parallel. For several independent screens it starts helpers that build one screen each, at the same time. Each helper only has Ocelot's own tools and runs inside the agent's sandbox.
- See and follow every agent. The toolbar shows each working agent; click to see what each one is doing and pick which one the camera follows (or all). Every agent's work is marked on the canvas in its own colour.
- Ask the agent about a layer. Select a layer and click the small button next to it (⇧⌘K): write what should change and add it to the chat, or send it right away. The agent gets exactly that layer.
- Task systems pick their display font deliberately: Geist stays for text, and an editorial, warm or playful brief gets a fitting display face.
- Privacy: the sandboxed agent now only ever sees a copy of the conversation it is working on, never your other conversations.

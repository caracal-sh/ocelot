- The agent works with omp 19.1 again. The new omp release added a reporting tool and a startup step that the agent's sandbox refused, so every message stopped with an error before the agent could start.
- More range and more refinement in what the agent designs. It picks a register for each brief (clear for product screens, bold for brand pages, playful for consumer products), takes the ground and the typeface from the brief instead of the same warm off-white, orange and serif on every project, and sets type the way well-crafted sites do: medium weights, tracking tightened to the size, three shades of ink and a single accent.
- See the direction before the first layer. When the agent sets up a document's own style, the chat shows it as a card: its name, mood and one-line direction, the colors with their roles, and the type. Adjust opens it in Assets > Styles; Another direction asks the agent for a clearly different one, keeping your content.
- Shader layers. Add a grain gradient, a mesh gradient, a halftone, a dither or film grain from the toolbar and tune its colors and look in the Inspector; it moves on the canvas, holds still under reduced motion and exports like any layer. Colors can follow the document's theme. The agent reaches for one only when the brief calls for a printed, filmic or screen texture.
- Fewer layout slips. Design inspection now flags a card or sticker painted over text, a headline half on a picture and half off it, and a picture that runs to one edge while the rest of the page keeps its margin; an off-centre warning names the layer that causes it.

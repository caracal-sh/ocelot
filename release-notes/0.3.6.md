- Conversation history in the agent sidebar. "+" starts a new conversation and keeps the old one; the clock button lists this document's conversations, and opening one continues it with everything the agent knew. Conversations are kept when you close the window or quit, stay outside the document (sharing a file never shares your chats), and can be deleted.
- No accidental stops: starting a new conversation, or switching, while the agent is working asks first.
- A design system made for the task. When a document has no style yet and you give no direction, the agent first creates one for this project: named colours, fonts and corner radii, saved with the document. Everything it draws uses them, so changing a colour or font in Assets › Styles restyles the whole design. Agents can do the same with `create_theme`.

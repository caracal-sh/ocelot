## Watch the agent design

- Each part the agent writes plays onto the canvas: an outline in the agent's colour, then the content top to bottom. A marker shows what it is writing ("Writing Hero"), and the view follows work that happens off screen, without pulling the view away while you scroll.
- With the built-in agent, a section grows on the canvas while the agent is still writing it, then settles into real layers in a single undo step.
- The agent is present from the moment you press Send. Steps in the sidebar say what was built ("Hero: headline and booking card"), and badges name the agent ("Claude is editing").

## Work with the agent

- Ask, queue and steer: agents can ask you multiple-choice questions; Enter queues a message while the agent works, ⌘↩ steers it mid-turn.
- Attach images, text files and long pastes to a prompt, in the sidebar and on Home.
- Image generation runs in the background while the agent keeps building. Choose the default image model in Settings › Images.
- **Hand off to an agent** (Export menu): copy a prompt for a coding agent, or save a folder with screenshots, React code, the design system and the motion, so the design gets implemented as drawn.
- Every action in the app is available to agents over MCP, including opening Ocelot, creating and saving projects, and changing settings. Security settings stay yours.

## Design systems

- Build your own design system on shadcn/ui with Base UI: eight styles, colours, radius, fonts and icons, light and dark, with a token editor that checks contrast.
- About 60 components and 23 blocks (login, sign-up, sidebar layouts) become real layers on the canvas: change a token and every instance follows.
- Tweak individual components, paste or copy shadcn preset codes, and export a shadcn registry or React code with real component imports.
- A Design system page shows every foundation and component.

## Better designs out of the box

- Geist is the default type family, including Geist Serif and Geist Pixel.
- Agents follow tighter guidance on layout, calm type, real imagery and motion, and a built-in inspection flags layout defects and unintended defaults.
- Screens that belong together are linked, so you can click through them in Preview.

## Everyday details

- Real tooltips, a fully keyboard-accessible Layers panel (⇧⌘L locks, ⇧⌘H hides), and "Back to content" when you have panned away from everything.
- Calmer motion throughout the app, with reduced motion respected everywhere.
- Opening a document from Finder or the command line now works in every case.
- Home moves to ⇧⌘1.

- Hand off a design as a front end or as a full app. In Export > Hand off to an agent, choose Build: "Front end only" (a Vite + React app, as before) or "Full app" (TanStack Start). For a full app the brief also lists the parts of the design that need a server, such as forms, sign-in and data lists, and how to build them safely.
- Handed-off screens fill the window. The instructions now tell the coding agent to make the page full height, so a screen shorter than the window no longer ends in a white band.
- React exports of halftone and dither layers that print a picture keep the picture as an image file next to the code instead of embedding it in the component, and React exports with code layers no longer fail a strict TypeScript check.
- The agent keeps its connection when the local model connection restarts while a chat is still closing its old connections; before, it could move to a new address and the chat stopped.
- Design inspection no longer asks about empty space below a screen whose content is centred.
- Lists in the agent's replies no longer show a stray dash or number while the reply is still being written.

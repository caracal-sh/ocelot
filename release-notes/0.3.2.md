- New: Patterns, under Assets › Patterns. 13 written specs for common product screens (sign in, onboarding, settings, dashboards, tables, detail pages, search, empty states, notifications, pricing, upgrade, checkout, permission prompts). Each lists the states to draw, copy rules, sizes and the mistakes to avoid. "Build with agent" hands one to the agent, optionally with a line about your product.
- Agents can look up the same patterns (`list_patterns`, `get_pattern`, which also matches a plain description such as "billing page") and read a new guide on product screens: one artboard per state (first use, no results, error, no access, loading) and one label per action.
- Inspection can now compare artboards on a page: the same action labelled differently, too many corner radii, and data screens missing their loading, empty or error state.

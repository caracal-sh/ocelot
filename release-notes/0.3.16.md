- Slash commands in the Agent sidebar. Type `/` to pick one: `/critique` reviews the selection or page without changing it, `/polish` fixes what the review finds, `/variants` has several agents build different directions side by side at the same time, `/responsive` makes tablet and mobile versions, `/flow` links the screens into a clickable prototype, and `/copy` rewrites the text only. `/new`, `/compact` and `/model` handle the conversation.
- Your own slash commands: put one Markdown file per command in the Commands folder (Settings › Agent › Open Folder) and it appears in the list. Agents you connect from outside see the same commands.
- The Agent sidebar works with every way of installing omp. Installed with Ocelot's own Install button (or with bun or npm), or through an install manager that keeps one file per version, omp was refused by the sandbox ("The sandboxed agent only runs omp") and no chat could start. Settings › Agent › Verify isolation now also checks that omp actually runs in the sandbox, and names the omp it found.
- React exports with live code layers are fully typed: the layers' JavaScript sits in its own file next to the screen, with a small typed runtime, instead of the whole screen turning type checking off.
- Agents connected to Ocelot can open Settings right after Ocelot starts; before, the request was answered as done while no window appeared until Settings had been opened once by hand.
